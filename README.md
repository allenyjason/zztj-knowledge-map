# 资治通鉴 · 知识图谱

把《资治通鉴》全二百九十四卷的人、事、关系，做成一张可以在浏览器里直接打开的交互图谱。

**6 个文件、共约 16.7 MB。不用装环境、不用起服务、不用联网**——把文件放在同一个目录，双击 `index.html` 就能看。

> 完全离线可用：拷到 U 盘、断网打开都能正常运行。前提是 6 个文件保持在同一目录、文件名不改。

---

## 它是什么

《资治通鉴》是编年体史书，人物散落在 1362 年、294 卷的流水账里。想看清「谁和谁是什么关系」「一件事背后牵扯了多少人」，靠翻书几乎不可能。

这个项目把全书抽成一张**人物关系网络**：

- **19,843 位人物**，其中 20 位是「臣光曰」里的论赞人物，单独标记
- **46,535 条关系**（君臣、父子、攻伐、举荐、谗杀、师承……）
- **24,287 件史事**，每件标注年份、参与人、地点
- **799 个地点**、**36 个政权实体**、**563 条同名异人消歧说明**

时间跨度从**公元前 454 年**到**公元 959 年**，约 315 万字原文。

## 文件清单

界面和数据是分开的：`index.html` 只有界面与逻辑，数据放在 5 个 `.js` 分片里。

| 文件 | 大小 | 内容 |
|---|---|---|
| `index.html` | 约 526 KB | 界面、样式与全部交互逻辑（D3 已内联） |
| `data-0-core.js` | 253 KB | 卷目与 303 条年份预设、36 个政权、799 个地点、563 条消歧说明 |
| `data-1-persons.js` | 3.14 MB | 19,843 位人物 |
| `data-2-relations.js` | 4.26 MB | 46,535 条关系 |
| `data-3-events-a.js` | 4.21 MB | 12,143 件史事（前 454 — 621） |
| `data-4-events-b.js` | 3.61 MB | 12,144 件史事（621 — 959） |
| **合计** | **约 16.7 MB** | **6 个文件，最大单文件 4.26 MB** |

`README.md` 和 `LICENSE` 是仓库说明与协议，**不参与运行**，传不传都不影响页面。

### 加载顺序

数据挂到全局对象 `window.__ZZTJ__` 上，由 `index.html` 用 `<script src>` 顺序加载：

```
index.html
 ├─ data-0-core.js       __ZZTJ__.meta / polities / places / disambiguation
 ├─ data-1-persons.js    __ZZTJ__.persons
 ├─ data-2-relations.js  __ZZTJ__.relations
 ├─ data-3-events-a.js   __ZZTJ__.events（前半）
 └─ data-4-events-b.js   在前半数组后追加后半
```

`data-4-events-b.js` 是在 `data-3-events-a.js` 的 `events` 数组后面 `concat` 追加的，所以**顺序不能打乱，也不能少了前半**。分片用 `<script src>` 同步加载，不走 `fetch`，因此 `file://` 直接双击也能用，不受浏览器跨域限制。

### 为什么拆成多个文件

- GitHub 网页上传单文件上限约 25 MB，把全部数据内联进一个 HTML 容易顶到上限；拆开后最大单文件只有 4.26 MB，网页拖拽毫无压力。
- 只更新某一类数据（比如补人物、改关系）时，重传一个分片即可，不用整包重传。
- 浏览器逐个解析 6 个脚本，首屏比一次性解析 20 MB 以上的 HTML 更快。

## 怎么用

### 本地打开

保持 6 个文件在同一目录，双击 `index.html`，或用任意现代浏览器打开它。

**无需联网**——没有 CDN、没有字体外链、没有 `fetch` / XHR，全部依赖都是同目录下的本地脚本；断网、拷 U 盘、打包成 zip 发送（解压后别拆散目录）都能直接用。

> 缺任一分片时页面会提示「数据文件未完整加载」，不会白屏。不要只单独拷贝 `index.html`，也不要改动分片文件名。

### 部署到 GitHub Pages

把 6 个文件放在仓库根目录 → **Settings → Pages → Branch 选 `main` + `/ (root)`** → 访问 `https://<用户名>.github.io/<仓库名>/` 即可。Pages 会自动打开根目录的 `index.html`，分片作为同目录静态资源一并加载。

### 三个核心操作

**① 按年份收敛**

左侧「年份区间」拖动滑块，或用「全」按钮一键回到全书范围。也可以点下方的**卷目树**（周纪一、秦纪一、汉纪一……共 294 卷）或**朝代行**（一键圈定该朝代全部卷）。

> 点卷或朝代时，区间会前后各放宽 5 年——因为人物的活跃期常横跨卷界（比如某人物「活动于前 445–前 359」，而卷界是前 403）。

**② 按中心人物展开**

在搜索框输入人名，或在图上点任意节点，即以该人为中心按「间接关联级数」展开子图。级数 2 级＝朋友的朋友。

**③ 「资」字布局**

右上角点「**资**」按钮，节点会沿一幅草书「资」字的笔迹重新排布；再点一次恢复力导向自由布局。

> 字形取自一幅草书「资」字手稿，逐点提取：228 个采样点，每点带粗细权重（0.121–0.537），笔顺按草书的提按节奏还原——顶部横画与底部贝环重按，右上转折与长撇提笔见锋。

## 配色：五德终始

节点颜色按**五德终始说**（邹衍的王朝德运理论）分配，不是随便挑的：

| 德运 | 正色 | 对应政权 |
|---|---|---|
| **水** | 黑 / 深蓝 | 秦（始皇尚黑）、汉（承秦水德）、北魏、匈奴、突厥 |
| **火** | 赤 | 周（尚赤）、蜀汉（炎汉）、隋、宋、明、西楚 |
| **木** | 青 | 东吴、北齐、北周、南齐、梁、陈 |
| **土** | 黄 | 唐（土德）、曹魏（土德代汉火）、新、后唐 |
| **金** | 白 | 晋、西晋、后晋、代 |

同代不同政权靠**明度分层**区分。比如同为木德的六个南朝政权：

```
东吴 #2b8c59 · 北齐 #4a8f5a · 北周 #2e7d5b · 南齐 #5c9c6a · 梁 #3d7a7a · 陈 #2a6b4a
```

**为什么汉用黑色而不是黄色？** 汉初承秦制，张苍主张水德；武帝太初改历后才改土德。这里取水德黑色，一是符合「汉承秦」的史实起点，二是黑色在浅绿底图上对比最强，而汉朝有 2,496 人，是全书最大的一片。

> 水德「尚黑」若用纯黑，两千多人会糊成一团。所以取**近黑的深蓝灰**（如汉 `#4a5a6e`），保留「黑」的意象又看得清。

## 数据从哪来

原文是《资治通鉴》二百九十四卷的通行本。抽取流程：

```
原文分段 → 实体识别（人名/地名/政权）→ 关系抽取 → 同名消歧 → 交叉校验
```

加工后的人工校验重点：

- **同名异人**：563 条消歧条目。比如「王成」有西汉胶东相（前 67 年在任）和东汉顺帝时人（125 年），跨 190 年，必须分开。
- **生卒年**：逐一核对，如王莽定为前 45 — 公元 23（新地皇四年为绿林军所杀）。
- **政权归属**：`power` 字段记录人物所属朝代。同名不同代按年份与文本拆分——曹魏/北魏/东魏/西魏、蜀汉/成汉/后汉/南汉、宋（刘）/南齐/梁/陈。

## 技术实现

**分片架构**。界面与数据分离，6 个本地文件按顺序加载，没有任何构建步骤、包管理器或服务端。

| 部分 | 说明 |
|---|---|
| 数据 | 5 个 `.js` 分片，挂到 `window.__ZZTJ__`，由 `index.html` 顺序加载 |
| 渲染 | 力导向图 + SVG（D3 内联在 `index.html`，不走 CDN） |
| 布局 | 力导向（link / charge / collide / center）或字形笔迹解锁 |
| 字体 | 系统字体栈，无外部字体 |
| 网络 | 无 `fetch` / XHR / CDN 请求，只有 6 个本地文件之间的 script 引用 |
| 依赖 | 无构建步骤、无第三方服务、无需起服务器 |

### 性能设计

46,535 条关系全量渲染会卡死。做法是：

1. **默认上限 500 节点**——按「重大事件锚点 → 中心距离 → 关联度」三级优先截取
2. **BFS 子图**——选中心人物时只展开其 N 级内邻域
3. **密度自适应**——按节点数动态缩放点径、碰撞半径、连线距离与斥力，让「点半径 ÷ 平均间距」稳定在 0.15–0.20

> 密度自适应解决的是：周纪 300 个点铺得开、汉纪 500 个点挤成一团的问题。缩放手系 = 平均间距 / 50px，钳制在 0.42–1.5。

## 使用提示

- 首次打开需解析约 16 MB 分片数据，低配设备约 1–3 秒，之后操作即时响应。
- 6 个文件必须同目录；`README.md`、`LICENSE` 是说明文件，可不上传。
- 论赞人物（20 位，如司马光）在图谱中默认不显示，需在「人物总览」页切到「仅论赞引文」查看。
- 支持 Chromium / Firefox / Safari 最新版。
